# Snake Water Gun Game - Python

A simple command-line implementation of the classic Snake, Water, and Gun game in Python. Challenge the computer in this fun decision-making game with clear rules and input validation.

## Description

This Python program implements a fun game of Snake, Water, and Gun where:
- The player inputs their choice (0 for Snake, 1 for Water, or 2 for Gun)
- The computer randomly selects its choice
- The game outcome is determined based on predefined rules
- Includes error handling for invalid player inputs

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SwapneelChaubey/Snake_Water_Gun_Game----Python.git
   cd Snake_Water_Gun_Game----Python
   ```

2. Ensure you have Python 3.x installed on your system.

## Usage

Run the game from the command line:

```bash
python Snake-Water-Gun-Game.py
```

Follow the on-screen prompts to play:
- Enter `0` for Snake
- Enter `1` for Water
- Enter `2` for Gun
- The computer will make a random choice and determine the winner

## Game Rules

The game follows these classic rules:

- **Snake drinks Water**: Snake wins
- **Water puts out Gun**: Water wins
- **Gun shoots Snake**: Gun wins
- **Same choice**: It's a tie

- User-friendly command-line interface
- Input validation with error handling
- Random computer selection
- Clear game outcome display
